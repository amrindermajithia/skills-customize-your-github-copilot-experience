# 🧪 Testing with pytest

## 🎯 Objective

Learn how to write unit tests for Python code using `pytest` by creating tests for small utility functions.

## 📝 Tasks

### 🛠️ Write tests for utility functions

#### Description
You will write `pytest` tests that validate the behavior of a set of utility functions provided in `starter_code.py`.

#### Requirements
Completed assignment should:

- Include a `tests/` directory with `test_utils.py` containing `pytest` tests for each function in `starter_code.py`.
- Tests should cover normal cases and at least one edge case per function.
- Provide clear assertions and use fixtures where helpful.
- Include a short `README` note on how to run tests (`pytest -q`).

---

Starter code and dependencies are provided as attachments. Register them using the repository helper scripts if you modify files.
